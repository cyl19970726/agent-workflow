Start with docs/product.md, docs/architecture.md, and docs/harness-roadmap.md for scope and implementation status.

Keep these capabilities modular. Core must not import a provider, PostgreSQL, SQLite, a UI, or a consumer repository. General persistence, runners, services, and UI belong in separate adapters/modules. Current shared packages provide core, PostgreSQL workflow-run storage, a read model, schema/storage contracts, the Workflow Space service/runtime/console, `@signal-room/workflow-skill-snapshot`, and an official OpenAI Agents SDK runner with a bounded SIWC Responses model transport. The official `@openai/agents` SDK owns the Agent turn/tool loop; the custom `Model` sends requests over the ChatGPT-authorized Responses route. This does not claim support for the complete Agents SDK surface, every deployment variant, or native session resume. SQLite is not an execution-store option: legacy SQLite data may only be handled by an explicitly invoked, read-only migration/import path. Legacy Codex traces are read-only evidence decoded by `workflow-read-model`; they are not an execution fallback.
