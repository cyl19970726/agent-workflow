Keep these capabilities modular. Core must not import Codex, PostgreSQL, SQLite, a UI, or a consumer repository. General persistence, runners, services, and UI belong in separate adapters/modules. See `docs/postgres-storage.md` for the implemented surface and `docs/harness-roadmap.md` for gaps. Keep domain methods and research skills in consumers.
