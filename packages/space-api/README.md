# Workflow Space read API

`./contracts` contains browser-safe DTO schemas. `./server` exports `createWorkflowSpaceApiHandler({resolveHost,cursorSecret})`, a Node handler that returns `false` only for paths outside `/api/workflow-spaces/v1/spaces/:spaceId`. Mount it before the host's fallback routes.

The host resolves the authenticated principal, authorization cache scope, principal-bound `WorkflowSpaceService`, CONTENT or other method scope, reader registry, optional business adapter, and deployment availability **on every request**. The handler calls the service's membership check on every matching request. The host must not reuse a service constructed for a different principal. `cursorSecret` needs at least 32 bytes; rotate it to invalidate old cursors.

Batch B adds exact validation reads: `/validation-plans/:planId/entries/:entryId` returns the frozen manifest's slot IDs, asset summaries and payload hashes, registered reader sections for those inputs, the last 30 attempts, trusted judge evidence, and at most 100 active Space tasks. It marks a task with a plan and entry only when the current plan summary has that exact run link. `/entries/:entryId/attempts/:attempt` returns one exact attempt. `/validation-plans/:planId/comparisons` and `/issues` are signed, paginated readbacks; comparisons require an exact pair and verified linked reviews, while issue evidence must link to this plan's entry, Case and optional run. Comparison/profile differences expose only an explicit safe field set. Input asset body appears only in registered reader sections or the existing asset reading route; manifest slot summaries omit it. The host may supply `inputSlotOrder` to show selected frozen slots first; unlisted slots keep their saved order. A trusted `inputSummary` callback receives only the exact saved assets for those slots and returns concise domain-specific labels; without it, the summary is empty. The reader selected by a frozen presentation has priority; when it declares none, a host reader registered as `<schema namespace>@<schema revision>` serves the exact input in both entry details and asset reading.

An authenticated host may inject `commands` and `commandSecurity`. Without both, all POST routes return 405 and `summary.capabilities.write` is false. The host supplies its public `origin`, a session-bound `csrfToken`, a `verifyCsrf(request,principal)` callback, and narrow `entryActions`, `startPlanEntry`, and `dispatchRun` methods. The API requires a nonempty exact Origin, `x-space-csrf`, the host verification callback, fresh Space membership, strict JSON request schemas, a frozen plan, exact entry/Case/manifest/method scope, and an exact linked run for dispatch. The explicit start route is `POST /validation-plans/:planId/entries/:entryId/attempts/:attempt/start` with `{ "inputManifestId": "..." }`; target-only recovery is `POST /validation-plans/:planId/entries/:entryId/attempts/:attempt/runs/:runId/dispatch` with `{}`. The host command adapter owns the fresh preflight gate, authoritative `(space,plan,entry,attempt)` idempotency, queue writes, and exact-run claim; the API does not construct an executor or call a generic queue wake. It clears its read cache after any command invocation, including a command that throws after a partial write. A successful receipt is checked against the frozen tuple and the resulting plan-run link before response.

Lists use signed keyset cursors bound to Space, cache scope, route, and filters. They are bounded to 100 items (default 30). `snapshotAt` is the response time, not a frozen database snapshot. The current `WorkflowSpaceService.overview()` source loads the full Space internally for directory reads, including asset payloads; the API projects bounded browser DTOs and returns bodies only from `/assets/:id/reading`, but database-level pagination remains future service work. Import and transformed assets appear in the unfiltered directory. Case/run filters include frozen manifest assets and recursively recorded dependencies.

Asset directory titles use the frozen presentation's matching schema label when the saved asset has no title. Reading links use the adapter's exact source refs and validated fragment pointers; unresolved refs stay unlinked. Where no adapter source refs exist, direct saved dependencies provide the fallback links.

After a directory page is selected, the API reads each represented producing run's process once and fills item `occurrenceId` and `round` from exact output bindings. Assets with no recorded output binding retain null identity; list responses still omit bodies. The method scope's short process cache is shared with reading details.

An imported or transformed asset has no run producer. Its relation view checks occurrence input bindings across the host's method scope to find exact consumers, while leaving producer and Case unset.

The handler keeps a bounded in-memory read cache (32 subject/Space/method scopes, 128 reads). Every request first calls the principal-bound service's `listSpaces()` for a fresh membership check, including cache hits; denial clears that scope. Concurrent reads of the same object share one pending call. Overview and mutable summaries expire after 2–4 seconds, immutable asset/context/manifest/presentation reads after 5 seconds, and terminal task-backed process views after 30 seconds. Errors are never cached. Responses still use `Cache-Control: no-store`.

The graph route returns self-contained Archify HTML under a sandbox CSP. The host embeds it with `sandbox="allow-scripts allow-downloads"` and accepts only `workflow-node-select` from the active iframe with a declared node ID. The parent may send `space-node-focus` to the same iframe; the adapter suppresses the resulting focus echo. The parent owns the node detail panel and never trusts the opaque iframe origin as authorization.
