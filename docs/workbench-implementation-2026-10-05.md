# Workflow Space 工作台实现记录（2026-10-05）

本轮依据 [工作台与展示契约](workbench-presentation.md)完成共享实现和 creation 接线。该主设计未由实现会话改写。以下区分代码能力、确定性验证与业务质量；没有把 MiMo 的内部审阅或运行状态改写成人类接受。

## 交付范围

共享 `packages/spaces` 现在提供独立的展示定义、追加式绑定、业务读模型和文档阅读式工作台。`/spaces/:spaceId` 有概览、案例、资产、方法迭代及次级执行记录、配置入口。原资产、上下文和会话链接继续访问；CONTENT 的 `/workbench` 和案例地址直接使用同一页面框架。

案例默认读取终态主产物，展示其准确流程评价与用户评价；过程按业务适配器提供的确切关系分组。同一运行内修订和两次运行的结果比较分开，后者展示输入、方法与实际配置条件差异。声明的比较字段保留顺序和原文，不把长度或执行成功当作质量提升。方法迭代连接实际评价、方法变更理由、验证运行、比较和采用记录；无记录时为空。

CONTENT 提供研究、稿件、模拟冷读、给定材料内事实核查及主编五类阅读器。最终稿通过原生终态收据与 Space 发布版本核对，审阅按准确依赖关联；研究资料标识仅在当时绑定的材料包和该研究的 notes 中解析。未知或冲突标识明确未解析。

## 三份合同的边界

- 业务正文仍由冻结的资产 schema 描述；节点读写仍由原存储合同约束。
- `WorkflowPresentationDraft` 的机器形状由导出的 `WORKFLOW_PRESENTATION_JSON_SCHEMA` 表达，语义检查由 `validateWorkflowPresentation` 完成。正文 schema、方法和展示各自版本化。
- 展示注册匹配完整 namespace、revision、hash。字段采用对象属性 JSON Pointer；不支持通配符、数组索引、复杂 schema 穿透或任意表达式。无法支持的路径要求已部署专用 reader，不能静默解释。
- 段落、字段组、列表、对象条目、表格、状态、准确来源及受管附件可组合。附件只链接当前资产登记的 blob；未知 reader 和不匹配 schema 采用安全的结构化回退。
- 专用 reader 和结果角色必须由服务宿主预先注册。声明不能执行 JavaScript、SQL、脚本或任意 URL，也不授予权限。

宿主构造 `WorkflowSpaceService` 的第四个参数可提供 `readerIds` 与 `resultRoleIds`。`registerPresentation` 保存不可变 revision；`bindPresentation` 追加准确 workflowVersionId／entrypoint 的绑定，记录判定主体和时间，以数据库序号保持顺序。`resolvePresentation` 返回当前视图与全部历史；资产证据区可以重开旧绑定的视图。没有运行时视图记录的历史运行标为后来配置的兼容绑定。

这套绑定不调用 `publishWorkflow`，不改方法定义 hash、运行 fingerprint 或旧资产。`runtimeEvidence` 只暴露经过成员检查的读取方法，保留 `runtimeLedger` 的写权限边界。共享渲染器核对业务适配器返回的结果、审阅及来源关系，避免串联其他运行或当前资料库的对象。

## 操作与阅读

运行、反馈修订、四问保存和明确接受沿用已部署的 `InteractiveWorkflowHost` 与业务服务。浏览、刷新和保存评价不自动调用模型。接受仍是明确按钮和服务关口，未通过的 CONTENT 不能借界面被接受。方法实验保留操作者 CLI，GUI 没有模拟实验记录。

四问草稿保存在浏览器会话内，按确切资产和表单区分，刷新不会清空。成功提交后清除对应草稿；提交失败保留。该草稿不是持久评价。当前服务仍是宿主绑定主体的本地工作台，没有新增生产级多用户登录、执行队列或云部署。

真实运行的三万余条流式事件按类型汇总，故障与恢复事件保持原顺序，全部原始事件仍保存在折叠证据中，避免执行页逐条铺开流式文本。

## 尚未扩展的边界

通用导航不包含 CONTENT 类型或业务文案；每个业务仍需部署准确的结果／关系适配器，不能由展示声明猜出最终产物。媒体专用排版、复杂 schema 的通用编辑器、序列对齐的自动质量判断、方法自动采用、生产多用户身份、队列、云部署与 VM 均不属于本轮。表格或文本差异不会替评价者得出“改善了”。

本轮没有提交或清理现有未提交工作，没有修改 CONTENT 方法、prompt、业务标准或执行引擎，也没有迁移研究和分析工作台。
