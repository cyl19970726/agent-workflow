# 交互工作流与节点详情

共享 Space 工作台使用固定版本的 Archify v3.0.1 渲染流程。方法定义与运行记录仍由 Space 提供；读取和刷新不启动模型、任务、发布或采用。

## 使用入口

- 已发布方法：`/spaces/{spaceId}/workflows/{versionId}/{entrypoint}`。
- 候选预览：交互宿主的 `/workbench/workflows/preview`。iframe 请求固定候选 ID；候选已变时返回 409，需刷新。
- 有运行时，在方法页面选择本版本、本入口的准确 run。运行图以全部方法节点为底图，标注已有实例状态和次数。
- 图支持搜索、聚焦、上下游、允许路径追踪、缩放、主题和导出。点击节点或搜索结果更新右侧详情，不重载图。
- 图下方的「独立看图与导出」打开同一版本、同一运行的查看器；SVG 导出保留类型颜色、状态边框和状态文字。
- 下方文字路径保留无脚本导航。窄屏使用上下布局。

详情包括节点用途、执行器、模型、工具、完整提示词、输入输出及绑定。选择 run 后可查看每轮实例、准确上下文、会话、实际记录配置、技术尝试与失败。冻结声明与运行时记录分开显示。

## 颜色与事实边界

| 执行类型 | 底色 |
| --- | --- |
| SDK / 适配器 Agent | 蓝色 |
| Codex | 紫色 |
| 程序 | 灰色 |
| 判断 | 橙色，附判断图标 |
| 人工 | 青绿色 |
| 未声明的 Agent | 中性灰蓝色 |

`WorkflowNodeDefinition.executor` 是可选声明，`family` 支持 `agent-sdk`、`codex`、`program`、`human`、`decision`，`adapter` 可说明具体执行器。CONTENT 的新声明明确标注 SIWC Responses；这不表示通用 OpenAI Agents SDK 已接入。历史精确配置 `executor.adapter: "SIWC Responses"` 也可被识别，其余缺失信息不猜。

底色表示类型。边框与文字标注运行状态：成功为绿色，失败／阻塞为红色，运行／待审为黄色；无映射记录为虚线。多次实例保留各状态的次数，详情保留逐次证据。失败优先的边框只是提示还有失败实例，不代表后续恢复无效。没有映射记录不证明从未执行。

箭头与交互路径始终表示合同允许的控制关系，不宣称实际执行或运行因果。自动流动动画关闭。历史 run 缺少当时的流程声明时，只有已登记的历史解释合同可提供兼容图，并明确标注为历史推导；不重写原版本或指纹。未映射步骤与覆盖度保留可见。

## 模块与集成

`packages/spaces/archify-render.ts` 从 process 节点和控制边生成 Archify IR，保留稳定 ID、并行、条件与返工。布局是确定性的列与分支适配，超长或复杂方法仍需后续视觉调优，不承诺任意代码自动恢复流程。

`diagram-host.ts` 与两个 console 提供鉴权后图入口。父页面只运行本站脚本；viewer 单独允许内联脚本并置于无 same-origin 权限的 sandbox。父页面校验消息来源窗口、允许节点 ID，服务器校验 Space、版本、入口、run 和 projection 一致性。图不携带节点完整 Prompt 或配置；详情在已鉴权的父页面读取。CSP 没有放宽到其他资源页面的内联脚本。

固定源码及本地改动清单见 [Archify 来源](../packages/spaces/third-party/archify/PROVENANCE.md)。creation 只提供业务标签和角色声明，不复制 viewer；其他消费者保持原栈。

当前状态是页面读取时的快照；刷新可更新状态，未加入后台推送。导出的图保留当前状态文字，但交互路径不等于已执行路径。
