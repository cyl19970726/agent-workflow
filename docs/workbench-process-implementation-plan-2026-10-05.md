## 范围与验收

1. 共享合同与持久化：准确方法绑定的流程合同、独立展示版本、运行冻结身份；复用存储节点端口与现有事实，关系发布具授权、幂等及原子收据。旧运行不回写合同或方法指纹。
2. 统一查询：实际节点实例、业务轮次与 attempt 分开，先后／并行／返工／多结果、关系邻域与片段。程序和 CLI 可读；未知、未映射、后来解释明确标识。
3. CONTENT 接线：声明现有流程与端口语义，用确切 phase/context/依赖/decide 投影 MiMo 三稿；第二稿可定位前稿、复用研究、前轮反馈、本轮三类审阅、后稿及原始执行证据。
4. 共享联动页面：紧凑摘要、方法／实际执行切换、轮次／节点／资产选择，手机等价列表。修材料片段、比较对象身份、中文字段、口播与画面阅读。
5. 验证和交付：隔离数据库确定性测试、相关类型与构建、文档链接、真实业务只读核验、独立实现记录及可用服务。
